# Edge Integrations

Current AiAction/OCCIVUE Edge work includes:

- **AXIS Camera Station** event/rule integration;
- **MQTT** event publication in applicable development builds;
- HTTP-based mechanisms in specific integration contexts.

Exact event names, MQTT broker details, topics, payload schemas, HTTP URLs and credentials are deployment-specific and must come from current integration documentation.

An HTTP integration should not automatically be described as a generic public webhook product. Notification channels such as email, SMS, mobile push or relay activation should only be claimed when the current deployment documentation confirms them.
