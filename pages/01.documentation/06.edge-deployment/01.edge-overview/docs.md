# OCCIVUE Edge Overview

OCCIVUE Edge is the product layer for complete ready-to-install computer-vision solutions deployed close to the monitored environment. It is based on the current AiAction solution and its evolution.

Edge is designed for customers that have cameras, or need a camera installation, and require continuous monitoring, local inference, decision logic and operational event integration rather than occasional API calls.

FireGuard and WaterWatch are current primary use cases. PPEWatch remains in development unless release documentation states otherwise.
