# Existing Cameras and Protocols

A key Edge design goal is to **reuse compatible existing camera infrastructure** where practical.

Current architecture work includes experience with:

- RTSP stream ingestion;
- ONVIF where applicable;
- AXIS VAPIX in relevant AXIS environments;
- AXIS Camera Station event/rule integration.

Existing-camera reuse depends on access to the required stream, credentials, codecs, network quality, resolution, field of view and the selected AI capability.

FireGuard's demonstrated approach is based on optical imagery; thermal cameras are not mandatory for the referenced smoke-detection tests.
