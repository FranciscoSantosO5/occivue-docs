# Site Assessment

An Edge site assessment should consider:

- monitored area and target event;
- existing cameras and field of view;
- stream access, resolution and codecs;
- network topology and connectivity;
- power availability and mounting positions;
- environmental conditions;
- edge-compute location and sizing;
- selected AI capabilities;
- event recipients and operational response;
- required integrations.

Hardware sizing depends on camera count, resolution, frame rate, number of modules, inference frequency and latency targets. Compact PCs have been used successfully in AiAction project work, but those examples are not universal sizing rules.
