# Commercial FAQ

## How much does OCCIVUE cost?
There is no single universal price. Platform uses an API/subscription model, while Edge is a project-specific installed solution.

## What are Platform API prices?
Final public subscription prices, quotas and plan limits are not defined in the current documentation.

## Can you quote an Edge project from camera count alone?
No. Site count, camera reuse, hardware, modules, installation, networking, integrations and support all affect the scope.

## Is ROI guaranteed?
No. OCCIVUE Edge can create strong value where manual monitoring or risk exposure is significant, but ROI depends on the customer's current cost and deployment context.

## How do I request a quote?
Provide the number and location of sites, camera inventory, selected use cases, infrastructure constraints, required integrations and support expectations to the commercial team.
