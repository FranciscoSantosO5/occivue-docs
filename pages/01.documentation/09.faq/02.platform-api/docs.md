# Platform & API FAQ

## Who is OCCIVUE Platform for?
Developers, software teams, systems integrators and organisations that want to integrate selected OCCIVUE visual-intelligence capabilities into their own software.

## Is the Platform a camera-management system for OCCIVUE Edge?
No. Its primary purpose is developer/API consumption of models and reasoning capabilities. Edge is a separate operational deployment experience.

## What authentication method does the API use?
The exact authentication scheme is not defined in the current general documentation. Use the current versioned API reference.

## What image formats and size limits are supported?
Those limits are API-specific and must come from the current API reference. They are not defined in the general knowledge base.

## Is there a free tier?
Free-trial or free-quota entitlements are release-dependent and not defined in the current knowledge source.

## What are the API rate limits?
Rate limits/quotas are intended to be enforced through API management, but exact values depend on the product/subscription and are not currently defined here.

## Can I monitor many live RTSP cameras through the API?
Continuous multi-camera monitoring is normally an OCCIVUE Edge use case unless the Platform release includes a specific documented streaming API.

## Is there a low-code/no-code builder?
It is a roadmap direction. It should not be treated as currently available unless the current release explicitly says so.
