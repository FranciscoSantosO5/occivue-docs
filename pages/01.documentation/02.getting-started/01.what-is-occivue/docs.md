# What is OCCIVUE?

OCCIVUE is the umbrella product architecture for reusable computer-vision intelligence. It is designed to make specialised visual-AI capabilities easier to consume, integrate and deploy without requiring every organisation to build and operate a complete vision stack from scratch.

OCCIVUE supports two main consumption patterns:

- **Developers and software teams** can use OCCIVUE Platform to access selected AI models and reasoning capabilities through controlled service interfaces.
- **Enterprises and public organisations** can use OCCIVUE Edge for complete camera-to-event deployments with local processing and operational integration.

The architecture separates the **AI capability** from the **way it is consumed**. For example, FireGuard is a fire/smoke visual capability. When supported, a capability can be exposed through Platform APIs, used inside an Edge deployment, or both.

OCCIVUE is a product/platform brand associated with AiTecServ. AiAction is the current applied vision-AI solution and technology family that is being transitioned into the OCCIVUE architecture, particularly the OCCIVUE Edge product direction.
