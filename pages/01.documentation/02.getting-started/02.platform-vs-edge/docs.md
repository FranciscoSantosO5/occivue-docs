# OCCIVUE Platform vs OCCIVUE Edge

The two product experiences solve different problems.

## OCCIVUE Platform

Use Platform when you want to **build software with OCCIVUE capabilities**. Its initial purpose is to expose selected proprietary computer-vision models and IDMR-related reasoning capabilities as controlled APIs that developers can integrate into their own applications.

Typical Platform questions include API access, developer subscriptions, quotas, credentials, request/response formats and programmatic integration.

## OCCIVUE Edge

Use Edge when you need a **complete operational deployment** connected to live camera streams. Edge is designed for continuous monitoring, local inference, decision logic and event integration close to the monitored environment.

Typical Edge questions include RTSP camera streams, local compute, site installation, camera compatibility, continuous monitoring, AXIS integration and MQTT event publication.

## They are complementary

Platform does not manage Edge as its primary purpose, and Edge is not simply a client of Platform. A customer can use Platform, Edge, or a combination depending on the use case and current product release.

A developer sending supported visual input to an API is using Platform. A site continuously monitoring several cameras with local inference and operational event rules is an Edge deployment.
