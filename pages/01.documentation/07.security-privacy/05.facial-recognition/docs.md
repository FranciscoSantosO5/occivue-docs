# Facial Recognition

The current OCCIVUE/AiAction product knowledge does **not establish facial recognition as a supported capability**.

Detecting a person, safety helmet or other PPE item is not the same as identifying an individual's face or identity. PPEWatch must not be treated as employee identification or biometric recognition unless a future approved capability and policy explicitly adds that functionality.
