# OCCIVUE Documentation

OCCIVUE provides reusable visual-intelligence capabilities through two complementary product experiences:

- **OCCIVUE Platform** — the developer-facing layer for consuming selected computer-vision models and decision/reasoning capabilities programmatically.
- **OCCIVUE Edge** — the deployment layer for complete on-site or near-site solutions that connect to camera streams, process visual data locally, apply decision logic and integrate events into operational workflows.

This documentation is primarily focused on **OCCIVUE Platform and developer integration**, while also documenting the Edge concepts, AI modules, deployment constraints, security boundaries and product terminology needed to choose the right architecture.

> **Current documentation status**  
> OCCIVUE Platform is being developed. Exact API endpoints, authentication methods, schemas, quotas, public pricing and portal entitlements must come from the current production API reference once published. This documentation intentionally does not invent those details.
