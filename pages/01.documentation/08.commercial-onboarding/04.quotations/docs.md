# Requesting an Edge Quotation

A meaningful Edge quotation normally needs:

- number and location of sites;
- camera count and camera types;
- whether existing cameras are expected to be reused;
- selected detection capabilities;
- edge-compute and networking needs;
- installation constraints;
- required external integrations;
- support expectations.

Camera count alone is not sufficient to calculate a binding quotation.
