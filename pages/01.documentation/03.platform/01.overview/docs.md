# Platform Overview

OCCIVUE Platform is the developer- and subscription-oriented part of OCCIVUE. It is designed for developers, software teams, systems integrators and organisations that want to consume specialised visual-intelligence capabilities without installing a complete camera-monitoring solution.

The first Platform phase focuses on wrapping selected proprietary computer-vision models and decision/reasoning capabilities behind controlled service interfaces.

The Platform is distinct from continuous CCTV monitoring. If your requirement is continuous monitoring of multiple live RTSP cameras, local inference and site-specific event rules, review **OCCIVUE Edge** instead.
