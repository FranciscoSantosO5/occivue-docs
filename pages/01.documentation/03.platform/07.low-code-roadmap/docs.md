# Low-Code / No-Code Roadmap

A later OCCIVUE Platform direction is to let users compose image-processing solutions from modular capabilities and generate integration code that uses OCCIVUE services.

This builder experience is part of the longer-term product vision. It is **not part of the initial API-only promise** unless a current release explicitly marks it as available.

Until then, developers should use the published API products and versioned technical reference that are available in the current Platform release.
