# PPEWatch Readiness Checklist

PPEWatch is currently **under active development**, so this page is a readiness checklist rather than a production deployment recipe.

1. Define the PPE classes required by the use case.
2. Review camera angle, distance and resolution.
3. Review occlusion, pose, lighting and scene density.
4. Confirm the current release supports the required classes before deployment.
5. Address privacy/data-protection requirements for imagery containing people.
6. Do not assume person detection provides identity or facial recognition.

Production code/API examples should only be added after the current release explicitly exposes PPEWatch through the relevant Platform or Edge interface.
