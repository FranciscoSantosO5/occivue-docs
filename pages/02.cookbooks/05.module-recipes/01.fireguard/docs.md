# FireGuard Deployment Checklist

1. Define the terrain/asset and required monitoring area.
2. Select an unobstructed camera viewpoint where possible.
3. Validate optical image quality at the expected smoke scale.
4. Review atmospheric visibility, haze, weather and lighting.
5. Validate stream compatibility with Edge.
6. Configure the appropriate event/reasoning conditions.
7. Define who validates and receives events.
8. Test the operational workflow before production use.

Do not convert the referenced ~30 km test evidence into a guaranteed design range. Validate the actual site and optics.
