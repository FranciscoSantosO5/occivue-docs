# Before You Build

Choose the consumption model first.

**Use OCCIVUE Platform** when your software needs programmatic analysis of supported visual input or OCCIVUE reasoning capabilities.

**Use OCCIVUE Edge** when your use case requires continuous live-camera monitoring, local inference, site installation and operational event integration.

Before implementing a Platform recipe, obtain the current versioned API reference. It is the authority for authentication, endpoint paths, schemas and executable code.
