# OCCIVUE Cookbooks

Cookbooks turn OCCIVUE concepts into practical implementation workflows.

> **Important current limitation**  
> The approved knowledge baseline does not yet publish exact OCCIVUE API endpoint URLs, authentication methods, request/response field names or executable schemas. For that reason, the current cookbook pack contains architecture-safe step-by-step recipes and pseudocode only. It intentionally does **not** fabricate runnable Python, JavaScript or `curl` requests.

When the versioned OpenAPI/API reference is published, these recipes should be updated with executable examples generated directly from that specification.
