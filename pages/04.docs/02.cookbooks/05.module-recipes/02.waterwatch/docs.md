# WaterWatch Deployment Checklist

1. Identify where visible water accumulation or flooding becomes operationally meaningful.
2. Position the camera so the target zone remains visible.
3. Review reflections, glare, moving objects and lighting changes.
4. Validate the stream and scene with the current WaterWatch release.
5. Define persistence/zone rules where applicable.
6. Define event recipients and external integrations.
7. Test representative dry and water-event conditions where practical.

WaterWatch is visual detection. Do not treat it as an exact water-depth sensor unless additional documented sensing is integrated.
