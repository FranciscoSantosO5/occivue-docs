# Current Platform Status

As of the current knowledge baseline, OCCIVUE Platform is being developed and its public site, API-management layer and commercial workflow are advancing in parallel.

The **initial Platform scope** is to expose existing OCCIVUE/AiAction AI models and IDMR-related capabilities as APIs so developers can submit supported visual input, receive structured results and integrate those results into their own software.

The following details are **release-specific and not yet final in the current knowledge base**:

- public Platform domain;
- endpoint URLs and endpoint catalogue;
- authentication scheme;
- request and response schemas;
- supported file formats and limits;
- rate limits and quotas;
- trial entitlements;
- subscription tiers and public prices;
- supported payment methods;
- developer-portal role model.

Low-code/no-code visual building tools are a **roadmap direction**, not part of the initial API-only promise unless a release-specific document explicitly marks them as available.
