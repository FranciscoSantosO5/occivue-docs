# Terminology and Capability Status

Use the following product names consistently:

- **OCCIVUE** — the overall visual-intelligence product architecture.
- **OCCIVUE Platform** — developer/API-oriented access to selected models and reasoning capabilities.
- **OCCIVUE Edge** — complete locally deployed camera-monitoring solutions based on the evolution of AiAction.
- **AiAction** — the current applied vision-AI solution and technology family; historical and current deployment material may still use this name.
- **FireGuard** — fire and smoke visual detection capability.
- **WaterWatch** — water and flood-related visual detection capability.
- **PPEWatch** — personal protective equipment monitoring direction; currently under active development unless a later release changes its status.
- **IDMR** — Intelligent Decision-Making Reasoning logic used around model outputs to decide when a detection is operationally relevant.

## Status vocabulary

**Available / operational** means implemented, subject to deployment-specific requirements.  
**Pilot / validated in trials** means tested in a pilot or trial, but not an unconditional production guarantee.  
**In development** means actively being built or improved and not generally available.  
**Planned / roadmap** means part of the intended product direction but not available today.  
**Not documented** means no approved current source defines the requested detail.

When a detail is not documented, do not infer it from industry conventions. Use the current API reference, release documentation or OCCIVUE support for confirmation.
