# Images, Video and Retention

The current general knowledge base does **not define a universal retention period** for OCCIVUE Platform or Edge visual data.

Whether raw video is stored, whether inference images are persisted and whether data is reused for model improvement must be answered from the current approved privacy/data-processing documentation for the applicable service or deployment.

Edge processing can reduce the need to transmit all video to a remote service, but that does not automatically mean that no data is stored or transmitted.
