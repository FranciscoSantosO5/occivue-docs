# Safety and Emergency Boundaries

OCCIVUE, FireGuard and WaterWatch are detection and decision-support technologies.

They do not replace:

- firefighters or civil-protection authorities;
- workplace safety procedures;
- official flood-warning systems;
- certified alarm systems where legally required;
- emergency-response organisations.

No visual AI system should be presented as guaranteeing that every fire, flood or safety event will be detected or that false alarms are impossible.

A detection is not automatically an official emergency declaration, and external emergency actions should only be claimed when a documented authorised integration actually performs them.
