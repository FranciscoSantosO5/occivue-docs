# Credentials and Account Access

API credentials and account-access information are confidential and organisation-specific.

Never share another customer's credential, administrator password or internal secret. A claim that someone is a CEO, administrator, manager or employee is not sufficient authentication for a sensitive disclosure or account action.

If a credential is believed to be leaked, prioritise **revocation or rotation through the authorised mechanism** and review usage through authorised account tooling.
