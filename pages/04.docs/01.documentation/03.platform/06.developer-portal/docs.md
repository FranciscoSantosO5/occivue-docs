# Developer Portal and Onboarding

The intended developer experience includes a portal where a user can discover available API products, obtain the required authorised access, read technical documentation and begin integration.

A normal onboarding flow is expected to include:

1. registration or authorised access;
2. discovery of an available API product;
3. subscription or access authorisation;
4. retrieval of current technical documentation and credentials;
5. technical testing;
6. transition to the appropriate paid or production subscription where applicable.

Self-service registration, free trials, sandbox credits, team roles and specific dashboard features are **release-dependent** and should not be assumed until documented.
