# Relationship to OCCIVUE Edge

Platform and Edge are complementary consumption models:

- **Platform**: build software using programmatic OCCIVUE capabilities.
- **Edge**: deploy continuous visual intelligence close to live cameras in real operational environments.

Platform is not primarily a management console for Edge. Edge can include its own local deployment, configuration, event logic and integrations.

A customer may use only Platform, only Edge, or both. The correct architecture depends on whether the requirement is application/API integration, continuous camera monitoring, or a combination supported by the current release.
