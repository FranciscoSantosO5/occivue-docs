# Initial Platform Scope

The initial Platform scope is API access to selected existing OCCIVUE/AiAction AI models and IDMR-related capabilities.

A typical integration pattern is:

1. discover an available Platform API product;
2. obtain authorised access according to the current onboarding process;
3. submit supported image or visual input;
4. receive a structured inference or reasoning result;
5. use that result in your own application, workflow or system.

The Platform packages specialised OCCIVUE capabilities so the consuming developer does not need to operate the complete Edge deployment stack.

Exact API behaviour is always version-specific and is defined by the current published API reference.
