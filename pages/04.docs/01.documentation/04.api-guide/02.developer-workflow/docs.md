# Developer Workflow

The normal developer journey is:

1. discover an available API product;
2. obtain subscription or access authorisation;
3. read the current technical reference;
4. authenticate using the documented mechanism;
5. submit supported visual input;
6. receive a structured result;
7. integrate that result into your application or workflow.

The exact steps, fields and credentials depend on the Platform release. Always use the current API reference for executable integrations.
