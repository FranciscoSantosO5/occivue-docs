# Common HTTP Errors

The following are **general HTTP meanings**, not a substitute for the current OCCIVUE API error reference:

| Status | General meaning |
|---|---|
| `400` | The request is invalid or cannot be processed in its submitted form. |
| `401` | Authentication-related failure. |
| `403` | Access is not permitted for the requested resource/product. |
| `404` | Resource or route not found. |
| `429` | Rate or quota limit reached. |

The current OCCIVUE API reference defines the exact error body, product-specific codes and remediation steps.
