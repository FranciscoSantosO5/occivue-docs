# Requests and Visual Input

OCCIVUE computer-vision APIs are intended to receive supported image or visual input and return structured AI results.

Exact values are API-specific for:

- supported file formats and content types;
- maximum file size;
- image dimensions;
- batch size;
- video support;
- request field names.

If the versioned API reference does not define a requested format or limit, treat that value as not currently documented rather than applying a generic web/API assumption.
