# Authentication

API access is intended to be controlled through the OCCIVUE Platform/API-management layer.

The exact authentication method is **not defined in the current general knowledge base**. Do not assume API keys, bearer tokens, OAuth or subscription keys unless the current API specification explicitly defines the mechanism.

Credentials are confidential and must not be shared in public support conversations or committed to source control.
