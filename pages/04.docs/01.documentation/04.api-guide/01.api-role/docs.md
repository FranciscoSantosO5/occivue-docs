# API Role in OCCIVUE

OCCIVUE APIs are the programmatic interface through which selected AI and reasoning capabilities are intended to be consumed. They belong to the **OCCIVUE Platform** product layer.

The initial API strategy is to expose existing proprietary computer-vision models and IDMR-related logic so developers can integrate OCCIVUE capability into their own applications without operating a complete Edge deployment stack.
