# Pricing Models

Platform and Edge use different commercial patterns.

## OCCIVUE Platform

Platform is intended to use API products/subscriptions and enforceable consumption policies. **Final public API subscription prices, free quotas and plan limits are not defined in the current documentation.**

## OCCIVUE Edge

Edge is a complete installed solution and is priced through a deployment-dependent quotation. Cost depends on factors such as sites, camera count and reuse, hardware, selected capabilities, installation, networking, integrations and support.

For current public pricing or a project quotation, use the current commercial channel rather than extrapolating from generic SaaS or camera-count assumptions.
