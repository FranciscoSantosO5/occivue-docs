# Platform Onboarding

The intended Platform onboarding flow includes:

1. registration or authorised access;
2. access to the developer portal;
3. subscription to an available API product;
4. retrieval of authorised credentials;
5. technical testing;
6. transition to the appropriate paid or production subscription.

Exact self-service registration, free-trial, sandbox-credit and account-verification behaviour is release-dependent and must come from the current Platform onboarding documentation.
