# AXIS Camera Station

AiAction has an established integration path with AXIS Camera Station for event/rule workflows.

If an expected event is not reaching AXIS Camera Station:

1. confirm the current AiAction/OCCIVUE software version and architecture;
2. verify the current documented event/rule configuration;
3. confirm network reachability and authorised credentials;
4. compare the event evidence at the OCCIVUE side with the AXIS rule/action state.

Use the current deployment guide for exact event names, URLs and credentials.
