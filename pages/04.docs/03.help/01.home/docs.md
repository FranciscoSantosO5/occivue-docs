# OCCIVUE Help & Support

Use this site to diagnose common OCCIVUE Platform, API, Edge, camera, integration and detection issues.

The support chatbot can help you identify the correct product area, collect the evidence needed for diagnosis and point you to the current documentation. It should not invent undocumented configuration values or claim that an account action has been performed unless an authorised connected tool actually performs it.

## Quick routes

- API access or HTTP errors → **Account & API Access**
- Camera or Edge connectivity → **Edge & Camera Troubleshooting**
- False positive / false negative → **Detection Quality**
- Alert/integration issue → **Integrations & Alerts**
- Credentials, data or GDPR → **Security & Privacy**
- Pricing, onboarding or quotation → **Billing & Commercial**
