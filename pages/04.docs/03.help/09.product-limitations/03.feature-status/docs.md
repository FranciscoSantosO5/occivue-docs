# Feature Availability

Some OCCIVUE capabilities are current, some are under development and others are roadmap directions.

Examples from the current knowledge baseline:

- FireGuard and WaterWatch are the more mature operational directions.
- PPEWatch is under active development.
- OCCIVUE Platform is being developed and exact public API details remain release-specific.
- low-code/no-code Platform building is a roadmap direction.

If a feature is not defined in the current release documentation, support should describe it as not currently documented rather than infer availability.
