# Authentication Problems

If an API request returns an authentication-related error:

1. verify that you are using the **current API documentation** for the product and version;
2. confirm that the authorised credential is being supplied exactly as documented;
3. confirm that the credential belongs to the correct account/product;
4. do not paste the secret into a public chat or ticket;
5. if a credential may be leaked, rotate or revoke it through the authorised mechanism.

The general knowledge base does not define a universal API-key, OAuth or bearer-token scheme. Use the current API reference for the exact method.
