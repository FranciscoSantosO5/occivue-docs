# Camera Compatibility

Compatibility depends on more than brand or resolution.

Check:

- accessible stream and credentials;
- RTSP/other supported stream mechanism;
- codec availability;
- image resolution and quality;
- network stability;
- field of view and camera position;
- selected AI module requirements.

RTSP is part of the camera-agnostic direction. ONVIF and VAPIX can be used where appropriate. AXIS integration experience exists, including AXIS Camera Station workflows.
