# GDPR and Data Retention

There is no universal retention period defined in the current general knowledge base. Retention, storage and data reuse must be determined from the current privacy/data-processing documentation for the applicable service or deployment.

OCCIVUE does not make every camera deployment automatically lawful under GDPR. Customers remain responsible for their legal basis, notices, access controls and operational procedures.
