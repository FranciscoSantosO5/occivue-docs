# Apparent False Positive

Collect the same evidence used for a false-negative investigation: original visual input, camera/scene context, time, conditions, version, configuration and returned result.

OCCIVUE IDMR can use persistence, probability, apparent area and monitored-area category to reduce operational noise, but it cannot guarantee zero false positives.

Do not disable safety monitoring as the first troubleshooting step without understanding the operational context.
