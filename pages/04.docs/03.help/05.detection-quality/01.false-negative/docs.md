# Apparent False Negative

If an expected event was not detected, collect:

- original image/video evidence;
- camera and scene information;
- timestamp;
- lighting, weather and visibility conditions;
- module/model version;
- relevant configuration;
- returned model/event result if one exists.

A human-visible event in a reviewed frame does not by itself prove a software defect. Camera geometry, visibility, timing and configured event logic all matter.
