# Camera Unavailable

Check the camera-to-Edge path in this order:

1. camera power and local device status;
2. network reachability from the Edge environment;
3. camera credentials and authorisation;
4. stream URL and stream availability;
5. codec and stream characteristics;
6. OCCIVUE Edge camera configuration;
7. module-specific image-quality requirements.

A camera-agnostic architecture does not guarantee compatibility with every camera. Exact commands and settings should follow the current deployment guide.
