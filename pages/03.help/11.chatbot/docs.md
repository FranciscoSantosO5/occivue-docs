# Using the Support Chatbot

The chatbot is designed to answer OCCIVUE product, developer and support questions using the approved knowledge base.

For the best result:

- state whether your issue is Platform, Edge or a specific AI capability;
- include non-secret technical context;
- include exact error status/text when appropriate;
- provide timestamps and versions;
- attach redacted evidence for detection issues.

The chatbot should be transparent when a requested detail is not documented. It should not fabricate endpoint names, prices, credentials, certifications, performance guarantees or customer-specific information.
