# MQTT Event Publication

MQTT publication has been implemented in current AiAction work for applicable fire/flood event integrations.

If MQTT events are not being received, verify the deployment-specific broker configuration, authentication, network reachability, subscription and payload documentation.

Topic names, broker addresses, credentials and payload fields are deployment-specific and should never be guessed.
