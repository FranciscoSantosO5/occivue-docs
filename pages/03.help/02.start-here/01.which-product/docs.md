# Which Product Area?

Use **OCCIVUE Platform** for API products, subscriptions, programmatic analysis and developer integration.

Use **OCCIVUE Edge** for live cameras, RTSP streams, local inference, edge hardware, site installation and continuous monitoring.

Use the relevant **AI capability** when the question is about what is being detected: FireGuard, WaterWatch or PPEWatch.

If your issue spans multiple layers, describe the full path: input/camera → model/API → reasoning/event logic → integration/notification.
