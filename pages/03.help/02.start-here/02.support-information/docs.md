# Information to Include in a Support Request

Provide only information relevant to the issue and avoid posting secrets.

Useful information can include:

- product layer: Platform, Edge or module;
- timestamp and timezone;
- request/event identifier if available;
- API version or module/software version;
- camera/site information for Edge issues;
- original visual input or short evidence segment for detection-quality issues;
- weather/lighting/scene conditions where relevant;
- expected result and actual result;
- integration destination and observed error;
- screenshots or logs with credentials redacted.

Never include API secrets, passwords or another organisation's data in a public support message.
