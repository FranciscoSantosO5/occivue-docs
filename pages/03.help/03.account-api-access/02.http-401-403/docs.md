# HTTP 401 and 403

`401` usually indicates an authentication problem. Verify the current credential and documented authentication method.

`403` usually means the request reached an authorised boundary but access is not permitted for the requested resource or product. Verify the subscription/product permissions and account configuration.

Exact OCCIVUE error bodies and remediation steps are version-specific and must come from the current API reference.
