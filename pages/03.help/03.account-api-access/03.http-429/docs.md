# HTTP 429 / Rate or Quota Limit

HTTP `429` generally indicates that a request rate or quota limit has been reached.

Check:

1. the product/subscription currently assigned to the account;
2. the current quota/rate-limit documentation;
3. recent usage if your authorised portal provides it;
4. the exact retry guidance in the API reference.

Do not assume a retry interval or quota value that is not documented for the current product.
