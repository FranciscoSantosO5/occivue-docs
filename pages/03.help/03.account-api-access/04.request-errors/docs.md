# Request and Input Errors

For a request that cannot be processed:

1. confirm the endpoint and API version in the current reference;
2. check the documented content type and request fields;
3. verify input format, size and dimensions against the endpoint specification;
4. compare the returned error body with the versioned error reference;
5. if the reference does not define the failing condition, collect the request identifier and escalate to support.

Do not infer unsupported file formats or request fields from another API.
