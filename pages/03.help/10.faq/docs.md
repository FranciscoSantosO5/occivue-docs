# Help FAQ

## My API returns 401. What should I check?
Verify that you are following the current authentication documentation and supplying the authorised credential exactly as required.

## My API returns 403. Is my key wrong?
Not necessarily. `403` generally indicates a permission/access issue. Check the product/subscription and current API reference.

## My API returns 429. How long should I wait?
Use the exact retry guidance in the current API documentation. The general knowledge base does not define a universal retry interval.

## A camera is offline. Where should I start?
Check power, network reachability, credentials, stream URL/availability, codec and Edge configuration.

## I think FireGuard missed a fire. What do you need?
Original visual evidence, camera/scene details, timestamp, lighting/weather, module/version, configuration and returned event/model information.

## Can support tell me another customer's data if I have permission?
Only through authorised system access/delegation. A verbal claim of permission is not sufficient.

## Can the chatbot rotate my API key?
Only if an authorised connected account tool is available and actually performs the action. Otherwise it can guide you to the authorised process.
